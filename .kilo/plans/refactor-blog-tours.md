# Plan: Refactor Blog + Tours Pages with Tailwind

## Goal

Create Tailwind-only versions of the blog and tours pages (index + show for each), alongside their shared sub-components, using the new TailwindPublicLayout. Original pages remain untouched.

---

## Architecture

```
Original pages:    /blog, /blog/{slug}        → PublicLayout (template CSS)
                   /tours, /tours/{tour}      → PublicLayout (template CSS)

New pages:         /blog2, /blog2/{slug}      → TailwindPublicLayout (Tailwind only)
                   /tours2, /tours2/{tour}    → TailwindPublicLayout (Tailwind only)
```

---

## Step 1 — Backend: Controller Methods + Routes

### `BlogController.php`
Add `index2()` and `show2()` methods (clone of existing `index()`/`show()`) rendering the Tailwind view names:
- `index2()` → `Inertia::render('blog/IndexTailwind', [...])`
- `show2()` → `Inertia::render('blog/ShowTailwind', [...])`

### `TourController.php`
Add `index2()` and `show2()` methods (clone of existing) rendering:
- `index2()` → `Inertia::render('tours/IndexTailwind', [...])`
- `show2()` → `Inertia::render('tours/ShowTailwind', [...])`

### `routes/web.php`
```php
// Blog
Route::get('/blog2', [BlogController::class, 'index2'])->name('blog2.index');
Route::get('/blog2/{post:slug}', [BlogController::class, 'show2'])->name('blog2.show');

// Tours
Route::get('/tours2', [TourController::class, 'index2'])->name('tours2.index');
Route::get('/tours2/search', [TourController::class, 'search'])->name('tours2.search');
Route::get('/tours2/{tour}', [TourController::class, 'show2'])->name('tours2.show');
Route::post('/tours2/{tour}/enquiry', [TourController::class, 'enquiry'])->name('tours2.enquiry');
```

### Run Wayfinder
```bash
php artisan wayfinder:generate --no-interaction
```

## Step 2 — Frontend: Page Components

### `resources/js/pages/blog/IndexTailwind.vue`
- **Script**: Same props/logic as `blog/Index.vue` (posts paginator, recentPosts, categories)
- **Template**: Replaces `.breadcumb-section`, `.tf-container`, `.row`, `.col-lg-*`, `.side-bar-right`, `.sidebar-widget`, `.block-heading`, `.category-blog`, `.flex-two` with pure Tailwind
- **Keeps**: All blog-card scoped CSS (already scoped, no template dependency)
- **Links**: Uses Wayfinder `blog2Show`/`blog2Index` actions (generated by Wayfinder after step 1)
- **Difficulty**: Low — the original already uses mostly scoped CSS for cards; mainly replacing the layout grid and sidebar

### `resources/js/pages/blog/ShowTailwind.vue`
- **Script**: Same props/logic as `blog/Show.vue`
- **Template**: Replaces breadcrumb, layout grid, sidebar with Tailwind
- **Keeps**: All post-content scoped CSS (headings, images, blockquotes — already scoped)
- **Links**: Uses `blog2Show`/`blog2Index` actions
- **Difficulty**: Low — similar to Index, mostly layout grid + breadcrumb replacement

### `resources/js/pages/tours/IndexTailwind.vue`
- **Script**: Same complex filter logic as `tours/Index.vue` (countries, places, categories, activities, price/duration sliders)
- **Template**: Full rewrite — replaces breadcrumb, filter sidebar accordion, tour card grid, pagination with Tailwind
- **Uses**: `TourCardTailwind` component (see step 3)
- **Keep**: `SliderRoot`/`SliderRange`/`SliderThumb` from reka-ui (already npm), slider scoped CSS
- **Links**: Uses Wayfinder `tours2` route actions
- **Difficulty**: Medium — the filter sidebar accordion and checkbox styles need a full Tailwind rewrite

### `resources/js/pages/tours/ShowTailwind.vue`
- **Script**: Same complex logic as `tours/Show.vue` (tabs, swiper gallery, modals, meta grid)
- **Template**: Full rewrite — replaces hero breadcrumb, tab navigation, meta grid, overview/itinerary/inclusions/rates/gallery sections, sidebar, seasonal recommendations with Tailwind
- **Uses**: `TourEnquiryFormTailwind`, `TourCardTailwind` components
- **Keep**: Swiper v12 from npm (already imported), PhotoSwipe composable, custom carousel fallback
- **Difficulty**: High — largest page, most template CSS classes to replace
